git# claudios_sabores_del_mayab_experencias
Sabores del Mayab Experiencias es una solución móvil diseñada para digitalizar la gestión de experiencias gastronómicas comunitarias en Quintana Roo. Su objetivo principal es conectar a turistas nacionales e internacionales con cocineras y cocineros locales mayas, permitiendo consultar un catálogo de experiencias.
